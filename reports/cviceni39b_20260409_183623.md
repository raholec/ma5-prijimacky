## 1. Správnost výsledků a postupů ✅ / ⚠️

Všechna vzorová řešení jsou **matematicky bezchybná**. Konkrétně:
- **1C:** `C/2 − C/6 = 400 → 2C/6 = 400 → C = 1 200 Kč`, ověření `600+400+200 = 1 200` ✓
- **2A:** `1.+2. = 168 Kč, 168 = 2C/3, C = 252 Kč, 3. = 84 Kč, 84−72 = 12 Kč` ✓
- **Vzorec sekce 5:** `2r + s + 2` je správně odvozen (řada nahoře = s+2, dva boční sloupce = 2r)
- **5C:** `r ≤ 13,5 → r ≤ 13`, celkem 13 obrazců ✓

Jediná stylistická nepřesnost: v **5C** se v řešení objevuje mezivýsledek `r ≤ 13,5`, který může žáka zmást — viz níže.

## 2. Soulad s testovými úlohami MA5 ✅ / ⚠️

Typové zastoupení (soustavy, MC, pravda/nepravda, grafy, vzory) **odpovídá reálné struktuře testu**. Celkové skóre 39 bodů přibližně odpovídá pásmu přijetí na víceleté gymnázium — záměr je legitimní.

- **Co zobrazit:** vlevo základní obrazec (r=3, s=4 světlé čtverečky), vpravo rozšířený (tmavý pruh nahoře + tmavé sloupce vlevo/vpravo), barevné popisky „přidaná řada = s+2 tmavých" a „přidané sloupce = 2r tmavých" + „+2 rohy"
- **Proč pomůže:** Bez obrázku žák neví, co vlastně počítá. Vzorec `2r + s + 2` je magický symbol — diagram ho změní na viditelnou realitu. Tohle je nejkritičtější chybějící vizuál na celém listu.

**🟠 Sekce 3B — Tři čtverce v řadě**
- **Typ:** inline SVG — 3 čtverce 5×5 v řadě, zvýrazněný vnější obvod (tučná linka), vnitřní dotyčné strany přerušovaně šedě
- **Co zobrazit:** viditelný rozdíl mezi vnějšími a vnitřními stranami; pod obrázkem čísla: 2×15 + 2×5
- **Proč pomůže:** Hint říká „nakresli si dlaždičky" — ale žák u obrazovky nemá papír. Obrázek udělá tuto práci za něj.

**🟡 Sekce 1A — Metoda krabiček**
- **Typ:** schéma (3–4 CSS divy s rámečky nebo SVG)
- **Co zobrazit:** 4 krabičky v řadě — 1 šedá (náramky) + 3 zelené (trička) + celkový počet 28 pod nimi, šipka „÷4 = 7"
- **Proč pomůže:** Textový popis krabiček funguje, ale vizuální krabičky jsou 5× rychlejší na pochopení.

**🟡 Sekce 1B — Výměna**
- **Typ:** schéma „před → po"
- **Co zobrazit:** 2 sošky 🗿🗿 → šipka → 3 trička 👕👕👕 (s textem „stojí stejně"), pak výsledná rovnice 5× 👕 = 300 Kč
- **Proč pomůže:** Klíčový mentální model „výměny" — žák ho vidí jako trik ze hry, ne abstraktní pravidlo.

### 2. Stávající SVG (sekce 4 — graf)

**Problémy:**
- Pruhy jsou příliš úzké (16 px) — na mobilu 320px se stanou tenčími
- Chybí **popisky hodnot** nad pruhy (např. „20", „10", „15") — žák musí hádat z mřížky
- Barvy `#1a1a1a` (Videí) vs `#888` (Textů) jsou v černobílém tisku k nerozeznání — použít vzor nebo jinou barvu (např. `#4f86c6`)
- Legenda je čitelná, ale `leg-dot` je 14×14 px — na mobilu malé

### 4. Technická doporučení

- SVG: vždy `viewBox` + `width="100%"` + `overflow:visible` — přizpůsobení mobilu ✓ (stávající graf to dělá správně)
- Hodnoty nad pruhy: `<text>` nad každým `<rect>` — pro print zásadní, osa nestačí
- Barvy pro tisk: vyhni se dvojici tmavě šedá + střední šedá — přidat alespoň jeden vzor (`fill="url(#hatch)"`) nebo jinou sytou barvu
- Krabičky a schémata: CSS flexbox s barevnými `div` rámečky funguje skvěle a nevyžaduje SVG — snadná údržba
